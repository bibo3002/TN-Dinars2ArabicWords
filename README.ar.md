# TN-Dinars2ArabicWords

**تحويل المبالغ بالدينار التونسي من الأرقام إلى العربية الفصحى ذات الاستعمال القانوني داخل Microsoft Word.**

**المؤلف / المشرف:** Habib FARHAT  
**الإصدار:** 3.4  
**المنصة:** Microsoft Word / VBA

[English](README.md) · [Français](README.fr.md)

## نبذة

TN-Dinars2ArabicWords هي وحدة VBA مخصصة لـ Microsoft Word لتحويل المبالغ المالية بالدينار التونسي المكتوبة بالأرقام إلى صياغتها بالحروف بالعربية الفصحى ذات الاستعمال القانوني، مع المحافظة على المبلغ الرقمي الأصلي بين قوسين.

مثال:

```text
2523.551 د
```

يصبح:

```text
ألفان وخمسمائة وثلاثة وعشرون دينارا وخمسمائة وواحد وخمسون مليما (2523.551 د)
```

صُمم المشروع خصوصا للوثائق القانونية والإدارية التونسية، مثل العقود والاتفاقيات والعرائض والمراسلات والمحاضر وغيرها.

## الخصائص

- دعم الدينار التونسي والمليم.
- اعتماد ثلاثة أرقام للمليمات.
- دعم الأرقام الغربية والعربية والهندية والفارسية.
- التعرف على صيغ شائعة مثل `د` و`د.ت` و`DT` و`TND` و`دينار`.
- معالجة المفرد والمثنى والجمع.
- صياغة عربية فصحى/قانونية.
- تحويل المبلغ المحدد أو جميع المبالغ في التحديد أو الوثيقة.
- منع إعادة تحويل المبلغ المحول مسبقا.
- توليد الحروف العربية باستعمال `ChrW`.
- اختبارات تراجعية.
- استعمال البادئة `TN33_` لتقليل تعارض الأسماء داخل `Normal.dotm`.

## التثبيت

1. افتح Microsoft Word.
2. اضغط `Alt+F11`.
3. اختر `Normal` / `Normal.dotm`.
4. اختر **File → Import File...** واستورد `TN_Montants_V3_3.bas`.
5. نفّذ **Debug → Compile Normal**.
6. احفظ `Normal.dotm`.

لا تفعّل وحدات VBA إلا من مصادر موثوقة، وراجع ملف `.bas` قبل استعماله في بيئة إنتاجية.

## الاستعمال

لتحويل المبلغ المحدد:

```vb
TN33_ConvertirMontantSelectionne
```

لتحويل جميع المبالغ في التحديد:

```vb
TN33_ConvertirMontantsSelection
```

لتحويل جميع المبالغ في الوثيقة:

```vb
TN33_ConvertirMontantsDocument
```

لتشغيل الاختبارات:

```vb
TN33_TesterV33
```

يمكن عرض نافذة التنفيذ الفوري في محرر VBA بواسطة `Ctrl+G`.

## البنية

تنقسم الوحدة منطقيا إلى:

1. التكامل مع Word.
2. اكتشاف المبالغ وتوحيدها.
3. توليد الأعداد العربية.
