# Changelog — mise à jour V3.4

## [3.4.0] — Déploiement Word global

### Modifié
- Remplacement du schéma RibbonX `customUI` par `customUI14` pour le modèle Word final.
- Documentation corrigée : TN-Montants ne doit pas être installé dans `Normal.dotm`.
- Installation recommandée via un `TN-Montants-V3.4.dotm` dédié chargé depuis le dossier Startup de Word.

### Ajouté
- Guide de déploiement multi-PC.
- Script PowerShell d'installation.
- Script PowerShell de désinstallation.

### Invariant fonctionnel
- Le moteur linguistique V3.3 reste la baseline de V3.4.
- Aucun changement linguistique volontaire n'est introduit par cette mise à jour.
